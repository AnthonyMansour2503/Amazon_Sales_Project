# Amazon Sales Dataset Analysis & Machine Learning Project

## Overview
This project analyzes a simulated Amazon sales dataset to identify key business trends and build predictive models for revenue estimation. 
The workflow includes data cleaning, exploratory data analysis, data visualization, and supervised machine learning to understand and predict revenue based on product and sales features.
The goal is to demonstrate practical skills in data analysis, machine learning, and business intelligence.

## Dataset
The dataset is a simulated Amazon sales dataset containing information such as:
- Product categories
- Country/region of sales
- Payment types and order status
- Brand information
- Sales revenue
- Yearly performance data

It is used for analysis and machine learning modeling purposes.

## Tools & Technologies
- Python

- NumPy  
- Matplotlib / Seaborn  
- Scikit-learn  
- XGBoost  
- MLP (Neural Network)  
- Jupyter Notebook  
- Power BI  

## Project Workflow

### 1. Data Cleaning & Preparation
- Handled missing values and inconsistencies in the dataset  
- Standardized data formats using Python (Pandas)  
- Prepared data for analysis and modeling  

### 2. Exploratory Data Analysis (EDA)
- Analyzed revenue trends by product category, country, brand, and year  
- Identified top-performing products and sales patterns  
- Generated visual insights using charts and graphs  

### 3. Machine Learning Models
- Built and evaluated multiple supervised learning models:
  - Linear Regression  
  - Random Forest  
  - XGBoost  
  - Multi-Layer Perceptron (MLP)  
- Compared model performance for revenue prediction  

### 4. Data Visualization
- Created visualizations to communicate insights clearly  
- Developed a Power BI dashboard to summarize key findings  

## Key Insights
- Identified the most profitable product categories and regions, with the electronics being the biggest category and the U.S being the biggest country  
- Observed clear patterns in revenue distribution across time and geography  
- Developed models capable of predicting revenue based on product and sales features
